# EchOverse Club — الموقع الرسمي لنادي إيكوفيرس الإعلامي

> **النادي الإعلامي لكلية العلوم والتكنولوجيا — جامعة محمد خيضر بسكرة**  
> **EchOverse Club — Media Club of the Faculty of Science and Technology, University of Biskra**

الحائز على لقب **أفضل نادي لكلية العلوم والتكنولوجيا** بجامعة بسكرة.

---

## 🌟 نظرة عامة (Overview)

موقع ويب متكامل من صفحة واحدة (Production-Ready One-Page Website) مصمم خصيصًا ليكون الهوية الرقمية الرسمية لنادي **EchOverse**.
تم تصميم الموقع بأسلوب تحريري سينمائي يجمع بين روح الشباب والاحترافية الأكاديمية، مع التركيز التام على تجربة الهاتف المحمول والوصول السريع عبر رمز الاستجابة السريعة (QR Code).

### 🎯 محاور النادي واختصاصاته:
- **التغطيات الإعلامية (Media Coverage):** توثيق الفعاليات بالصورة والفيديو عالي الجودة.
- **المقابلات والحوارات (Interviews):** لقاءات مع الأساتذة، الطلبة والضيوف.
- **صناعة المحتوى (Content Creation):** ريلز، جرافيك، وسرد قصصي رقمي.
- **تنظيم وصناعة الفعاليات (Event Organization):** المساهمة في إخراج فعاليات وتجارب طلابية مميزة.

---

## 📸 التوثيق البصري ومعرض الصور الحقيقي

يعتمد الموقع حصريًا على الصور الحقيقية الخاصة بأنشطة وتكريمات النادي:
1. **صورة الفريق مع السيد عميد الكلية:** إبراز العلاقة الوثيقة والشراكة مع عمادة كلية العلوم والتكنولوجيا.
2. **لحظة التتويج بجائزة أفضل نادي:** توثيق تسلم درع التميز وشهادة التقدير بحضور عميد الكلية والأساتذة بقاعة عمر عساسي.
3. **تكريم النادي مع السيد مدير الجامعة:** صورة رسمية لدرع التميز مع مدير جامعة محمد خيضر بسكرة.
4. **التغطيات الميدانية والفعاليات:** لقطات توثيقية أمام مبنى الكلية والأقسام الأكاديمية.
5. **استعراض الأعمال الإعلامية:** تقديم مخرجات النادي أمام القيادة الجامعية.
6. **عتاد التصوير والمعدات:** استعراض الكاميرات الاحترافية ومعدات الصوت الميدانية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Vite + React:** سرعة فائقة في البناء وزمن استجابة فوري.
- **تصميم مخصص بالكامل (Custom CSS Design System):**
  - خط **Alexandria** العربي الهندسي الفاخر من Google Fonts.
  - خط **Plus Jakarta Sans** للعلامة اللاتينية.
  - لوحة ألوان مستوحاة من الفحم والأوبسيديان الداكن مع لمسات الكوبالت الأزرق، وتدرجات ذهبية لوسام التميز.
  - دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`).
- **عارض صور مخصص (Accessible Lightbox):** يدعم التمرير باللمس على الهواتف (Touch Swipe)، والتنقل بالأسهم، وزر الإغلاق، ومفتاح Escape.
- **توافق بنسبة 100% مع GitHub Pages:** جميع المسارات نسبية (`base: './'`).
- **سير عمل آلي عبر GitHub Actions:** ملف `.github/workflows/deploy.yml` لنشر الموقع بضغطة زر واحدة.

## 🚀 التشغيل والبناء محليًا (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# معاينة النسخة الإنتاجية
npm run preview
```

ينتج عن أمر `npm run build` مجلد `dist/` جاهز للنشر المباشر على أي استضافة ثابتة أو GitHub Pages.
