- **Name:** EchOverse Club (نادي إيكوفيرس الإعلامي)
- **Affiliation:** النادي الإعلامي لكلية العلوم والتكنولوجيا - جامعة محمد خيضر بسكرة (Mohamed Khider University of Biskra)

- **Framework:** Vite + React (Ultra-fast, fully static, zero-backend)
- **Hosting:** GitHub Pages with automated GitHub Actions workflow (`.github/workflows/deploy.yml`)
- **Path Resolution:** Relative asset paths (`base: './'`), robust against arbitrary repository subdirectories.
